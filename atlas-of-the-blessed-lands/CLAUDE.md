## How Nawaz likes to work
- He is a complete beginner (Windows 11, PowerShell). Use plain language. Go ONE step at a time and wait for his confirmation (a screenshot is best) before the next step.
- Push back honestly if a request is contradictory or unclear. Do not just agree.
- Keep what the classical sources say clearly separate from your own reasoning or general knowledge. Label every claim: Qur'an / hadith / early scholars / classical geographers / modern borders / Claude's synthesis / Nawaz's specification. Say plainly when something is unverified; do not present inference as established scholarly consensus.
- Always write "Allah ﷻ" with the honorific (build.js adds ﷻ automatically after the name, except inside names such as ʿAbd Allāh).

## Standing rules for the content
- Qur'an, translation and tafsir only from quran.ai (Saheeh International; al-Baghawī, al-Ṭabarī on 5:21, Ibn Kathīr on 24:55). If the quran.ai connector is not set up, do not quote verses from memory — say so and ask Nawaz to connect it (`claude mcp add --transport http quran_ai https://mcp.quran.ai`).
- Hadith only with collection, number and grading (sunnah.com, dorar.net). Leave out anything not verified; `notes.md` lists what was verified and what was not.
- The outlines are a thought experiment / Nawaz's specification, not from the sources and not a ruling. Say so wherever it matters.
- LEAVE NO AREA OUT (Nawaz, 2026-10-11): when he asks for a land, take ALL the area it occupies, even where it crosses into another modern country (e.g. China). Never clip a traced or requested region to a set of countries, never drop pieces as "fitting error" or because they are small (islands, slivers), and never leave out towns or strips he names. If a part seems doubtful, include it and tell him, rather than leaving it out.

## Web access and tools (since 2026-10-12)
- The cloud environment allows sunnah.com, dorar.net, www.iranicaonline.org, en.wikipedia.org, archive.org, www.naturalearthdata.com, portal.opentopography.org and download.geofabrik.de (Nawaz set Network access to Custom).
- sunnah.com, dorar.net and iranicaonline.org answer plain curl/WebFetch with a Cloudflare "Just a moment" 403; open them with the Playwright Chromium instead (executablePath /opt/pw-browsers/chromium, a normal desktop user agent, wait about 10 s), which gets through. Use this to check hadith numbers and gradings directly.
- The setup script installs scipy, shapely, pyproj and rasterio for Python.
- *.archive.org is allowed too (Version 95): the Mapzen terrain tiles at https://ia600905.us.archive.org/33/items/terrain_mapzen_pmtiles/terrain.pmtiles (Terrain-RGB, 512 px tiles, zoom 0–10; height = -10000 + (R·65536 + G·256 + B)·0.1 m). Read them with tools/dem_fetch.py (needs `pip install pmtiles`). The DEM files (tools/data/dem_*.npz) are not in git or the zip.
